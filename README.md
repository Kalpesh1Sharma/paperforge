# PaperForge

> Turn messy research into polished documents using AI agents and SuperDocs.

PaperForge is an AI-powered research workspace that converts folders of PDFs, notes, markdown files and documents into structured, professionally formatted reports.

## Features

- 📂 Folder Upload
- 🤖 Multi-Agent Pipeline
- 📑 Research Synthesis
- ✨ SuperDocs Integration
- 📄 DOCX Export

## Tech Stack

- FastAPI
- React
- OpenAI / Groq
- SuperDocs API
- Docker
